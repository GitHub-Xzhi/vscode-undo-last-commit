# 撤销上次提交 (undo-last-commit)

在 VSCode「源代码管理」视图的标题栏添加「撤销上次提交」图标按钮，点击后对当前工作区执行 `git reset --soft HEAD~1`，将上次提交的改动退回到暂存区。

## 功能

- 在源代码管理视图（Git Provider）标题栏显示撤销图标
- 点击后弹出确认对话框，防止误操作
- 自动检测当前活动编辑器所在的工作区
- 无提交记录时给出友好提示

## 使用方式

1. 打开一个 Git 仓库
2. 切换到「源代码管理」面板
3. 点击标题栏的向左箭头图标（撤销上次提交）
4. 在确认框中点击「确认撤销」

## 编译

```bash
npm install
npm run compile
```

## 调试

按 `F5` 启动扩展开发宿主窗口，在新窗口中打开任意 Git 仓库即可测试。
